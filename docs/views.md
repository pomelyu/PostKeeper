## 主要頁面
主要頁面藉著底下的 Navigation Bar 切換。由左到右排列分別是
1. MainView - 使用者進入app時的主頁面
   1. 顯示最新收到和最新加入的明信片。點選後進入該明信片的 PostcardView
   2. 提供快速新增明信片的按鈕
   3. 顯示釘選的收藏夾，以供快速進入。點選後進入 PostcardEditView
2. KeeperView - 以收藏夾或是清單的方式顯示收藏的明信片
   1. 提供按照日期先後排序的清單形式
   2. 提供依地區分資料夾的顯示方式
   3. 提供自訂收藏夾的顯示方式，並可新增或刪除收藏夾
   4. 提供搜尋的功能，搜尋結果由清單的形式顯示
   5. 此頁面中，點選特定明信片後進入該明信片的 PostcardView
3. MapView - 以地圖的方式顯示收藏的明信片
   1. 提供依「寄件」或「收件」地點標示的地圖模式
   2. 提供依地區的篩選器，篩選結果以 grid 的方式顯示。點選特定明信片後進入該明信片的 PostcardView
4. UserView - app的各項服務設定
   1. 顯示使用者的收藏總覽
   2. 提供個人資訊的編輯
   3. 提供備份與還原
   4. 提供通訊錄的設定
   5. 提供 app 語言切換


## 次要介面
次要介面從主要介面或是其他次要介面進入，均提供返回來源介面的功能
1. PostcardView - 顯示明信片的正反面和寄件、收件資訊。
   1. 按下「編輯」按鈕進入 PostcardEditView。
   2. 按下「返回」後回到進入前的頁面
2. PostcardEditView - 提供兩步驟的明信片編輯。按下「取消」後回到進入前的頁面
   1. 第一步驟讓使用者可以開啟相機拍照或是從相簿中選取已有的照片。按「下一步」進入步驟二
   2. 第二步驟讓使用者可以編輯「收件」與「寄件」者的資訊。按「儲存」返回進入前的頁面
3. ContactView - 提供管理預先定義的人物和地點。在填寫收件或寄件人時，地點會自動帶入
4. CollectionView - 以雙欄的方式顯示內含的所有明信片
