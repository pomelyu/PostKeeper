# UI 設計規範

## 1. 設計定位

本產品是明信片收藏與管理 App。介面以鼠尾草綠、奶油紙白、文具元素與白虎角色建立品牌識別，呈現溫暖、安靜、具有旅行記憶的收藏體驗。

設計參考：

- `./resources/ui_elemetns.png`：功能圖示、收藏插畫、白虎角色與操作元件。
- `./primary_views.jpg`：首頁、收藏、地圖與個人頁面。
- `./secondary_vies.jpg`：掃描、資料填寫、明信片詳情與收藏夾。

本文件將參考圖的視覺語言轉為實作規範。以下色碼、字級與尺寸是正式採用的設計值，不代表原始圖片內含的設計變數。實作以本文件為準。

## 2. 設計原則

1. 使用低彩度自然色，讓明信片內容成為視覺焦點。
2. 以留白、細框線與底色區分層級。
3. 使用圓角矩形與膠囊形建立一致的柔和輪廓。
4. 同一層級的元件共用尺寸、字級、顏色與間距。

使用規則：

- 頁面以 `background` 為底，主要操作使用 `primary`。
- 一個操作區域只設一個主要動作，其餘使用描邊或文字按鈕。
- 藍色、卡其及插畫中的粉色、黃色只用於插畫，不用來表示操作狀態。
- 內文使用 `textPrimary` 或 `textSecondary`，不使用主綠色作為一般內文顏色。
- `primary` 搭配白字只用於 18 sp、700 字重的主要按鈕與選取分頁；小型文字使用淺綠底搭配深色字。
- 狀態同時透過文字、圖形或填色變化表達，不只依靠顏色。

## 4. 文字系統

### 字體與單位

- 繁體中文與英文統一使用 **Noto Sans TC**，隨 App 打包，避免裝置字體差異改變版面。
- 數字與日期沿用相同字體。
- 字級使用 sp，間距與元件尺寸使用 dp；文字遵循系統字體縮放設定。
- 字距設為 0，不拉寬中文字距。
- 以下行高為預設字體比例下的基準值；系統放大文字時同步放大行高。

### 字級級距

| 層級 | 字級 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `displayTitle` | 28 sp | 700 | 36 sp | 首頁與主要分頁的大標題 |
| `pageTitle` | 24 sp | 700 | 32 sp | 明信片詳情標題、獨立頁面標題 |
| `sectionTitle` | 18 sp | 700 | 26 sp | 區塊標題、收藏夾名稱、主要按鈕與選取分頁 |
| `body` | 16 sp | 400 | 24 sp | 一般內文、輸入內容、欄位名稱、設定項目 |
| `label` | 14 sp | 500 | 20 sp | 日期、張數、欄位補充、步驟標籤與未選取分頁 |
| `caption` | 12 sp | 500 | 18 sp | 底部導覽標籤與縮圖輔助資訊 |

### 文字使用規則

- 主要按鈕與選取分頁使用 18 sp、700 字重；分頁切換時維持固定寬度與高度。
- 重要欄位值使用 16 sp、500 字重，內文段落使用 16 sp、400 字重。
- 12 sp 只用於輔助資訊，不用於表單輸入、主要操作或核心內容。
- 段落、表單內容與說明文字靠左對齊；按鈕、分頁及底部導覽標籤置中。
- 清單標題最多顯示兩行，超出以省略號表示；詳情頁顯示完整標題。
- 系統文字放大時，表單列與按鈕隨內容增高，不裁切文字。

## 6. Icon 規範

### 功能圖示

- 使用單色線框圖示，採 24 × 24 dp 設計格線。
- 標準描邊寬度為 2 dp，端點與轉角使用圓角。
- 預設圖示使用 `iconDefault`，選取圖示使用 `textPrimary`，主要按鈕內圖示使用 `primaryContent`。
- 工具列、設定列表與一般按鈕圖示尺寸為 24 dp；底部導覽圖示尺寸為 26 dp。
- 每個獨立操作圖示提供至少 48 × 48 dp 的點擊區域。
- 功能圖示不加入紙紋、漸層、多色填色或陰影。
- 搜尋、返回、關閉、新增、分享、刪除與設定使用一致的圖示造型，不在不同頁面替換風格。

### 選取狀態

- 底部導覽中，首頁、收藏、地圖與個人圖示使用線框未選取狀態及實心選取狀態。
- 選取項目增加 `selectionBackground` 膠囊底色，並保留文字標籤。
- 開關與勾選框同時改變填色與圖形，明確顯示狀態。

## 8. 操作元件

| 元件 | 設計規則 |
|---|---|
| 主要按鈕 | 綠底白字，18 sp、700 字重；按下切換為深苔綠 |
| 次要按鈕 | 紙白底、深色字、1 dp 框線；文字使用 18 sp、700 字重 |
| 文字按鈕 | 深色文字搭配方向圖示，保留 48 dp 最小點擊高度 |
| 輸入框 | 紙白底、細框線、16 sp 文字；聚焦時使用 2 dp 主色框線，外部尺寸不變 |
| 分頁 | 未選取為淺米底深字；選取為主綠底白字 |
| 勾選框 | 未選取為紙白底框線；選取為綠底白色勾號 |
| 開關 | 關閉為灰色軌道；開啟為綠色軌道，圓形滑塊移至右側 |

| 底部面板 | 標題、輸入內容與操作按鈕依序排列；取消置左、確認置右 |
